# Переход со старого формата ссылок

Раньше ссылка в каталоге neurodoc записывалась одним UUID в угловых скобках: `<uuid>`.
Теперь ссылка выглядит как `[текст](uuid)`, а старая форма ссылкой больше не считается.
Если открыть каталог прежнего формата, редактор сам предложит перевести его на новый, а
перед переводом сделает полную резервную копию.

## Чем старая форма отличается от новой

Было:

```text
Подробности — в документе <5c673c53-8ad9-49eb-9fb6-ffb3954848f0>.
```

Стало после перевода:

```text
Подробности — в документе [](5c673c53-8ad9-49eb-9fb6-ffb3954848f0).
```

Пустой якорь `[]` по формату означает «показать вместо текста ссылки заголовок целевого
файла». В редакторе такая ссылка выглядит кружком, а на Windows и Linux заголовок цели
виден в подсказке при наведении мыши. Синтаксис ссылок подробно описан в главе
[Ссылки](../format/links.md).

Пока каталог не переведён, `<uuid>` для приложения — просто текст. Каталог выглядит так,
будто в нём нет ни одной ссылки: по старым ссылкам нельзя перейти, путей от `root` нет,
почти все файлы попадают в «Файлы без входящих ссылок», а «Битые ссылки» старые ссылки
не замечают.

## Когда приложение предлагает перевод

При каждом открытии проекта приложение считает в его файлах вхождения вида `<uuid>`.
Если они есть, сразу после открытия `root` появляется вопрос:

| | Windows и Linux | Android |
| --- | --- | --- |
| заголовок | «Каталог в старом формате» | «Каталог прежнего формата» |
| согласиться | «Преобразовать» | «Перевести» |
| отложить | «Не сейчас» | «Не сейчас» |

В тексте вопроса сказано, сколько старых ссылок и в скольких файлах найдено, и что перед
изменением будет создана резервная копия всего каталога.

«Не сейчас» ничего не меняет. Вопрос повторится при следующем открытии проекта: пока в
каталоге остаются ссылки старого вида, приложение будет предлагать перевод.

## Что делает перевод

1. **Резервная копия.** Папка каталога копируется целиком, со всеми вложенными папками,
   включая скрытые, например `.git`. Если копию сделать не удалось, перевод не
   начинается, ни один файл не меняется, а приложение сообщает об ошибке: «Не удалось
   преобразовать каталог», на Android — «Миграция не выполнена».
2. **Замена ссылок.** Каждое `<uuid>` становится `[](uuid)`, а UUID приводится к нижнему
   регистру. Весь остальной текст, включая переводы строк, остаётся байт в байт прежним.
3. **Описание формата.** Если `ReadMe.md` в корне каталога (имя — в любом регистре) всё
   ещё описывает прежний формат по старому шаблону приложения, файл целиком заменяется
   актуальным описанием. Старый шаблон приложение узнаёт по характерной фразе из него:
   если вы переписали `ReadMe.md` и этой фразы в нём не осталось, файл не трогается.
4. **Перечитывание.** Каталог перечитывается с диска. На Windows и Linux заново
   открывается `root`, а история «Назад» и «Вперёд» очищается.

На Windows и Linux итог показывается в окне «Каталог преобразован»: сколько ссылок
переведено и в скольких файлах, обновлено ли описание формата в `ReadMe.md` и полный путь
к резервной копии. На Android итог и путь к копии появляются во всплывающем сообщении.

Голые UUID без угловых скобок перевод не трогает: они остаются просто текстом.

> [!WARNING]
> Перевод проходит по всем файлам, которые читает приложение, — не только по `root` и
> `_content`, но и по файлам в собственных форматах: YAML-контрактам, конфигам,
> Markdown. Если в таком файле `<uuid>` встречался как обычный текст, он тоже станет
> `[](uuid)`. Проверьте изменения после перевода: сравните с резервной копией или, если
> каталог лежит в git, посмотрите `git diff`.

## Где резервная копия

| Платформа | Папка |
| --- | --- |
| Windows | `%APPDATA%\NeurodocEditor\backups\` |
| Linux | `~/.local/share/neurodoc-editor/backups/` |
| Android | `backups/` в приватной папке приложения |

Внутри для каждого перевода создаётся папка с именем `<id проекта>-<ГГГГММДД-ЧЧММСС>`.
Здесь id проекта — внутренний идентификатор из настроек приложения, а не название
проекта. Проще всего найти нужную копию по пути, который приложение показывает после
перевода.

Копии автоматически не удаляются. Когда вы убедились, что всё в порядке, их можно
удалить вручную. На Android приватная папка доступна только самому приложению и
исчезает вместе с ним при удалении.

## Если что-то пошло не так

В резервной копии лежит каталог ровно в том виде, в каком он был до перевода. Чтобы
вернуться, скопируйте её содержимое обратно на место каталога. Если каталог в git, можно
просто отменить незакоммиченные правки средствами git. На Android копия лежит в
приватной папке приложения, куда обычный файловый менеджер не заглядывает, поэтому там
откатываться удобнее через git.

## После перевода

Все переведённые ссылки получают пустой якорь и в редакторе выглядят кружками. Внутри
предложения обычно лучше настоящий текст ссылки. Чтобы вписать его, включите «Как есть»
и наберите текст между квадратными скобками (см. [Редактирование и
ссылки](editing.md)).

Если каталог лежит в git, правки перевода — обычные изменения файлов. Отправьте их на
сервер, как любые другие (см. [Совместная работа через git](git.md)).
