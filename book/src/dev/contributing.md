# Как помочь проекту

Проект открыт: ошибки, идеи и правки принимаются на GitHub, в репозитории
[vabuter/neurodoc](https://github.com/vabuter/neurodoc). Здесь — как предложить правку и
какие правила действуют в репозитории.

## Сообщить об ошибке или предложить идею

Заведите [issue](https://github.com/vabuter/neurodoc/issues). Чтобы ошибку можно было
повторить, укажите:

- платформу — Windows, Linux или Android;
- версию: на Windows и Linux она в заголовке окна, на Android — внизу диалога настроек;
- шаги, которые к ней привели, — лучше всего на каталоге-примере `example/`;
- если приложение упало — запись из журнала ошибок: на Windows это
  `%APPDATA%\NeurodocEditor\error.log`, на Linux — `~/.local/state/neurodoc-editor/error.log`;
  у Android-версии своего журнала нет.

Не прикладывайте свои настоящие каталоги и файлы настроек: в `settings.json`
Android-версии лежат git-токены.

## Предложить правку

Правки приходят pull request'ом в ветку `main`: форк, ветка, PR. Опечатку в книге проще
всего поправить прямо на сайте — значок правки в шапке страницы открывает её исходный
файл в `book/src/` на GitHub.

Перед тем как отправить PR, проверьте:

- [ ] **Три версии.** Поведение одинаково на Windows, Linux и Android, а доменный код
      меняется на трёх платформах вместе.
- [ ] **Описание.** Изменилось поведение — поправлены `doc/` и книга; изменились сборка
      или зависимости — README версии и глава [Сборка](build.md); найдено неочевидное
      решение — оно записано в `CLAUDE.md`. Где что описывать, подсказывает глава
      [Устройство репозитория](repository.md).
- [ ] **Проверки.** Для Linux — `cargo test`, при правках интерфейса — самопроверка
      (`NEURODOC_SMOKE`); Windows и Android — запуском. Всё — на копии `example/`: сам
      эталонный каталог при тестировании не меняют, см. [Проверки](testing.md).
- [ ] **Версия.** Номер нигде не записан руками: его даёт git-тег при выпуске, см.
      [Версии и выпуски](versioning.md).
- [ ] **Ничего приватного** — об этом ниже.

## Язык

Язык проекта — русский: интерфейс, комментарии в коде, документация и сообщения
коммитов. Исключение — bat-файлы: cmd ломает разбор UTF-8 с кириллицей даже после
`chcp 65001`, поэтому они написаны по-английски и в ASCII. sh-скрипты в корне тоже
англоязычные: двойники bat-файлов повторяют их сообщения, остальные написаны так же.

Термины в тексте — как в интерфейсе приложения: «Как есть», «Связать», «Прочитано»,
«Далее», «Сохранить на сервере».

## Коммиты

Устоявшийся в истории репозитория стиль:

- **Заголовок** — по-русски, что изменилось, без точки в конце. Если правка касается
  одной платформы или одной подсистемы, она называется в начале: «Linux: …»,
  «Android: …», «Слежение за диском: …».
- **Тело** — почему понадобилась правка (что было сломано и как это проявлялось), что
  сделано, как проверено («Проверено: …») и какая документация обновлена.

Примеры заголовков из истории:

```text
Linux: прокрутка просмотра не сбрасывается, «рука» над ссылками
Android: убраны deprecated-предупреждения сборки
Слежение за диском: свою запись отличаем по содержимому, а не по времени
Версия приложения из git-тега
```

## Ничего приватного

- В репозиторий не попадают настройки приложений (`settings.yaml`, `settings.json`),
  журналы, `local.properties` с локальным путём к SDK, ключи подписи (`*.jks`,
  `*.keystore`) и токены. Большую часть этого уже отсекает `.gitignore`, но проверьте
  `git status` перед коммитом.
- Проверяют на копии `example/`, а в примерах берут выдуманные имена и адреса:
  зарезервированные для примеров домены (`example.com`, `*.example`) и IP-адреса из
  документационных диапазонов. Никаких личных путей, имён чужих проектов и адресов почты в
  коде, документации и снимках экрана.
- Настоящие каталоги — свои и чужие — при проверках не открывают.

## Лицензия

Проект распространяется по лицензии MIT — текст в файле
[LICENSE](https://github.com/vabuter/neurodoc/blob/main/LICENSE) в корне репозитория. В
приложения встроены сторонние компоненты со своими лицензиями:

| Компонент | Лицензия |
| --- | --- |
| highlight.js 11.9.0 | BSD-3-Clause |
| marked 12.0.2 | MIT |
| Asciidoctor.js 2.2.8 | MIT |
| шрифты Inter и JetBrains Mono | SIL Open Font License 1.1 |

Тексты лицензий highlight.js и шрифтов лежат в `windows/NeurodocEditor/Assets` рядом с
файлами (`Highlight/LICENSE.txt`, `Fonts/*-LICENSE.txt`), а у marked и Asciidoctor.js
лицензия указана в заголовке самого файла. Добавляя библиотеку или шрифт, положите рядом
текст лицензии, допишите строку в таблицу лицензий в README и не забудьте копию для
Android-версии (см. [Устройство репозитория](repository.md)).
