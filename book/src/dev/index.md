# Для разработчиков

Этот раздел — для тех, кто хочет собрать Neurodoc Editor из исходников, поправить его
или перенести на новую платформу. Приложений три, а функциональность у них одна, поэтому
почти любая правка здесь — правка сразу в трёх местах.

## Пять правил проекта

1. **Одна функциональность — три версии.** У Windows (C# / WinUI 3), Linux (Rust / GTK4) и
   Android (Kotlin / Jetpack Compose) одни и те же пользовательские истории. Правку формата
   или поведения доводят до всех трёх.
2. **Домен портирован «файл в файл по смыслу».** Ядро каталога и git-слой на Linux и
   Android повторяют своих двойников на C#. Расхождение в них — ошибка, а не особенность
   платформы.
3. **Описание идёт вслед за кодом.** Изменилось поведение — поправьте `doc/` (документацию
   в самом формате neurodoc) и эту книгу (`book/`).
4. **Версия — только git-тег** `vX.Y.Z` на ветке `main`. В файлах сборки и в коде номера нет.
5. **Проверяют на копиях.** Эталонный каталог `example/` при тестировании не меняют, а
   настоящие каталоги пользователя не трогают вовсе.

## С чего начать

Проще всего войти в проект через Linux-версию: у неё есть автотесты и самопроверка
интерфейса, а собрать и запустить её можно одной командой из корня репозитория:

```bash
./linux-run.sh
```

Чтобы при этом не задеть свои настоящие проекты, запускайте отдельный экземпляр с
собственными настройками — как это сделать, рассказано в главе [Проверки](testing.md).

Если вы пришли за форматом, а не за кодом, начните с главы
[Формат neurodoc](../format/index.md), а как разбирать каталог своей программой, рассказывает
[Каталог глазами программы](../format/for-programs.md). Как пользоваться самим редактором —
в разделе [Neurodoc Editor](../editor/index.md).
