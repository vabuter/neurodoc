# Neurodoc Editor для Android

Мобильная версия редактора каталогов **neurodoc** с теми же функциями и оформлением,
что и десктопные версии из `windows/` и `linux/`: тёмная графитовая тема, teal-акцент,
компактные ссылки, навигация как в браузере, прогресс чтения, автосохранение.

## Технологии

- Kotlin + Jetpack Compose (Material 3)
- minSdk 30, compileSdk 37
- Настройки — JSON в приватной папке приложения (аналог `settings.yaml` в Windows-версии)
- Просмотр форматов — WebView + highlight.js / marked.js / Asciidoctor.js
  (лежат в `assets/highlight`, встраиваются в страницу инлайном, работают офлайн)

## Сборка и установка

Из корня репозитория:

```bash
./android-build.bat
```

Сборка и установка на подключённый по USB телефон:

```bash
./android-install.bat
```

На Linux — `./android-build.sh` и `./android-install.sh`. Если нет ни `local.properties`,
ни `ANDROID_HOME` / `ANDROID_SDK_ROOT`, они берут SDK из `~/.local/opt/android-sdk`
(Android Studio при установке нужно указать тот же путь).

Вручную (из `android/`):

```bash
./gradlew.bat assembleDebug
```

На Linux:

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Debug-APK подписан ключом той машины, где собран (`~/.android/debug.keystore`), и поверх
приложения, собранного на другой машине, не встанет. Либо перенесите ключ, либо удалите
приложение — вместе с ним удалятся его настройки.

## Доступ к файлам

Каталоги neurodoc лежат в общей памяти устройства, поэтому приложению нужен доступ
«Ко всем файлам» (`MANAGE_EXTERNAL_STORAGE`). При первом запуске появится диалог с
кнопкой, ведущей в системные настройки. Выдать разрешение можно и через adb:

```bash
adb shell appops set --uid today.vab.neurodoceditor MANAGE_EXTERNAL_STORAGE allow
```

## Возможности

- **Проекты** — список «название + путь к каталогу»; путь можно ввести вручную или выбрать
  системным пикером папок. Каталог, `root`, `_content` и `ReadMe.md` создаются автоматически.
- **Редактор** — открывается `root`. Ссылка `[текст](цель)` показывается одним лишь своим
  текстом с подчёркиванием, служебная часть скрыта; ссылка без текста — кружком «●».
  Тап открывает файл, http(s)-адреса — браузер. Пройденные ссылки становятся серыми.
- **Ссылки по пути** — вместо UUID в ссылке может стоять путь к файлу в собственном формате
  (`[auth.start](../contract/auth/start.yaml)`), считается от файла, где написана ссылка.
- **Как есть** — чип в строке под шапкой: файл показывается ровно как на диске, со всеми
  служебными символами. Нужен, чтобы править текст посимвольно.
- **Прогресс чтения** — тонкая полоса под шапкой и счётчик «прочитано/всего». Файл
  отмечается прочитанным через 3 секунды после открытия либо чипом «Прочитано» вручную;
  чип «Далее» ведёт к следующему непрочитанному файлу в порядке обхода от `root`.
  Файлы в собственных форматах в обход чтения не входят.
- **Навигация как в браузере** — «Назад» / «Вперёд» в шапке, кнопка «домой» к `root`;
  при возврате в файл восстанавливаются каретка, прокрутка и режим просмотра.
- **Хлебные крошки** — кратчайшие пути от `root`, с горизонтальной прокруткой.
- **Связи файла** — панель с входящими ссылками, битыми ссылками и файлами без входящих.
- **Поиск** — по текущему файлу (с подсветкой совпадений и счётчиком) и по всему проекту
  (с фрагментами; тап открывает файл и выделяет вхождение).
- **Поиск и замена** — область: текущий файл или весь проект.
- **Открыть файл** — принимает голый UUID, `root`, путь (`contract/auth/start.yaml`) или
  текст с UUID внутри; подставляет цель из буфера обмена, есть фильтруемый список файлов.
- **Действия** — новая ссылка (якорем становится выделенный текст или слово под курсором),
  «Связать» выделенный текст со ссылкой из буфера, «Снять ссылку» (текст остаётся),
  новый свободный файл, копирование ссылки и содержимого, обновление с диска,
  удаление файла («только файл» / «файл и ссылки»).
- **Просмотр форматов** — SVG / JSON / YAML / Bash / MD / AsciiDoc / HTML / nginx.
  В отрендеренных MD и AsciiDoc ссылки neurodoc кликабельны.
- **Git** — пункт «Git…» в меню: приложение само является git-клиентом (JGit),
  системный git на Android не нужен. Публикация, клонирование, ветки с автостэшем,
  «Сохранить / Получить / Синхронизировать», история с дельтами. Авторизация —
  токеном (github.com / gitlab.com) из «Настройки Git…»; токены хранятся только на
  устройстве и не попадают в облачный бэкап. Имя и почта автора коммитов задаются
  там же. Текущая ветка видна в верхней панели.
- **Миграция каталога** — каталог со ссылками прежнего формата `<uuid>` приложение
  предлагает перевести на новый формат, сделав перед этим полную копию каталога
  в своей приватной папке.
- **Версия приложения** — внизу диалога настроек, из git-тега `vX.Y.Z`
  (см. «Версионирование» в [README.md](../README.md) в корне репозитория).
- **Настройки** — тема (Системная / Светлая / Тёмная), шрифт (JetBrains Mono, Inter,
  системный), размер шрифта, междустрочный интервал.
- **Сохранение** — автоматическое, как в IDE; плюс сохранение при уходе приложения в фон.

## Отличия от десктопных версий

Горячие клавиши десктопа заменены на пункты меню и жесты — на телефоне нет клавиатуры
с модификаторами. По той же причине не переносились чисто клавиатурные операции
(перемещение строк Shift+Alt+↑/↓, отступы Tab, Ctrl+Y и т.п.).

## Структура

```
android/app/src/main/java/today/vab/neurodoceditor/
├── MainActivity.kt          — точка входа, доступ к файлам, буфер обмена, диалоги
├── data/
│   ├── NeurodocCatalog.kt   — домен: файлы, граф ссылок, пути, поиск, замена
│   ├── CatalogMigration.kt  — перевод каталога с прежнего формата (с копией)
│   ├── ReadingProgress.kt   — прогресс чтения (свой файл на проект)
│   └── Settings.kt          — настройки и список проектов (JSON)
└── ui/
    ├── EditorViewModel.kt   — состояние: файл, история, чтение, автосохранение, поиск
    ├── EditorScreen.kt      — экран: шапка, крошки, строка чипов, редактор, панели
    ├── EditorText.kt        — разбор и показ ссылок, подсветка совпадений
    ├── FormatViewer.kt      — просмотр форматов в WebView + переход по ссылкам
    ├── Dialogs.kt           — проекты, настройки, замена, открыть файл, миграция, справка
    └── theme/               — палитра и шрифты (те же, что в десктопных версиях)
```
