# Neurodoc Editor

Десктоп-приложение для Windows 11 для просмотра и редактирования каталогов документации
в формате **neurodoc** (описание формата — в [README.md](../README.md) в корне репозитория).

Работа с каталогом напоминает браузер: файлы связаны ссылками вида `[текст](uuid)`,
по которым можно переходить кликом, а редактирование — как в обычном текстовом
редакторе с автосохранением.

## Технологии

- C# / .NET 10
- Windows App SDK (WinUI 3), unpackaged, self-contained
- YamlDotNet — настройки приложения в YAML (`%APPDATA%\NeurodocEditor\settings.yaml`)

## Сборка и запуск

В корне репозитория есть готовые скрипты:

- `build-debug.bat` — сборка Debug (x64);
- `build-release.bat` — сборка Release (x64);
- `build-deploy.bat` — сборка Release и публикация в папку деплоя
  (по умолчанию `C:\d\deployments\neurodoc_editor`, меняется переменной
  `DEPLOY_DIR` в начале скрипта). Публикация самодостаточная: папка содержит
  .NET-рантайм и Windows App SDK, приложение запускается на любой
  Windows 11 x64 без установки зависимостей.

Вручную:

```bash
dotnet build NeurodocEditor/NeurodocEditor.csproj -c Debug -p:Platform=x64
```

Запуск:

```bash
./NeurodocEditor/bin/x64/Debug/net10.0-windows10.0.22621.0/win-x64/NeurodocEditor.exe
```

Release-сборка: `-c Release` (путь к exe меняется соответственно).
Для ARM64: `-p:Platform=ARM64`. Внимание: `dotnet build` без `-p:Platform`
собирает первую платформу по алфавиту (ARM64) — платформу лучше указывать явно.

## Возможности

- **Версия приложения** — в строке заголовка окна, сразу после названия, из git-тега `vX.Y.Z`
  (см. «Версионирование» в [README.md](../README.md) в корне репозитория).
- **Проекты** — список «название + путь к каталогу», текущий проект открывается при старте.
  При создании проекта каталог, файл `root`, папка `_content` и `ReadMe.md` создаются автоматически.
- **Редактор** — открывается `root`; neurodoc-ссылки `[текст](uuid)` подсвечиваются, курсор над ними
  меняется на руку, клик выполняет переход к файлу.
- **Действия**: вставить новую ссылку (создаёт файл и переходит к нему), создать свободный файл,
  скопировать ссылку на текущий файл в буфер (`[заголовок](имя-файла)`), удалить файл
  с подтверждением, переход к root, кнопка «Назад» (Alt+←).
- **Удаление файла** спрашивает, что делать со ссылками на него. «Только файл» оставляет их
  битыми. «Файл и ссылки» снимает ссылки во всём каталоге, но **текст ссылок сохраняет** —
  его писал автор, и он часть предложения; исчезает только сама ссылка.
- **Хлебные крошки** — кратчайшие пути от `root` до текущего файла (если минимальная
  длина у нескольких путей — показываются все такие); каждая «крошка» кликабельна.
  Длинные пути прокручиваются по горизонтали — скроллбаром или колесом мыши
  над панелью.
- **Обратные ссылки** — панель со списком файлов, ссылающихся на текущий; клик — переход.
- **Поиск по файлу** (Ctrl+F) — панель в редакторе: счётчик «n из m», Enter /
  Shift+Enter — следующее/предыдущее, Esc — закрыть.
- **Поиск по проекту** (Ctrl+Shift+F) — по всем файлам, с фрагментами и подсветкой
  совпадений; клик по результату открывает файл и выделяет вхождение.
- **Поиск и замена** (Ctrl+R — область «текущий файл», Ctrl+Shift+R — «весь
  проект», или кнопка в тулбаре) — окно с полями «Найти» / «Заменить на» и
  переключаемой областью поиска; кнопки «Заменить», «Заменить всё», «Отмена».
  Замена в текущем файле откатывается одним Ctrl+Z.
- **HTTP-ссылки** — адреса `http(s)://…` в тексте подсвечиваются синими
  «пилюлями» и кликабельны: открываются в браузере по умолчанию (завершающая
  пунктуация предложения не считается частью адреса).
- **Сохранение** — автоматическое (как в IDE), Ctrl+S или F2 форсируют запись.
- **Навигация как в браузере** — кнопки «Назад»/«Вперёд» в тулбаре, Alt+← / Alt+→;
  новая навигация по ссылке обнуляет историю «вперёд» (как в Firefox). При возврате
  в файл каретка встаёт на своё последнее место в нём (в рамках сеанса).
- **Ctrl+G** — переход по ссылке, на которой стоит каретка (внутри `[текста](uuid)` или
  вплотную к краям ссылки); **Ctrl+T** — «Новая ссылка» (вставить ссылку в позицию
  каретки, создать файл и перейти к нему); **Ctrl+N** — «Новый файл» (свободный,
  без привязки к другим).
- **Открыть файл** (Ctrl+O или кнопка в тулбаре) — окно с полем ввода: принимает голый
  UUID, `root`, путь к файлу в собственном формате (`contract/auth/start.yaml`) и даже
  текст, внутри которого есть UUID; если в буфере обмена лежит ссылка, она подставляется
  автоматически. Ниже — список файлов проекта с фильтром по имени и заголовку
  (файл открывается двойным щелчком или кнопкой «Открыть»).
- **Шпаргалка по клавишам** — кнопка «?» в углу или F1.
- **Git** — кнопка Git в панели инструментов: опубликовать проект на сервере,
  клонировать, переключать/создавать/удалять ветки (правки при переключении
  прячутся в stash и возвращаются), «Сохранить на сервере» (commit+push),
  «Получить с сервера» (pull), «Синхронизировать»; история коммитов с изменёнными
  файлами и диффами — карточкой в правой панели. Текущая ветка видна в строке
  заголовка. Используется установленный в системе git и его учётные данные;
  при конфликте — выбор: серверная версия, своя (push --force) или отмена.
- **Просмотр форматов** — кнопки SVG / JSON / YAML / Bash / MD / AsciiDoc / HTML
  в шапке редактора: SVG отображается как рисунок, JSON форматируется с отступами
  и подсвечивается, YAML и Bash подсвечиваются, Markdown и AsciiDoc рендерятся
  как документы (код-блоки с подсветкой), HTML отображается как страница.
  Отжали кнопку — снова текст; этот выбор запоминается за файлом, и при возврате
  к нему режим восстанавливается. Реализовано на WebView2 (входит в Windows 11) +
  highlight.js, marked.js и Asciidoctor.js (Assets\Highlight, лицензии BSD/MIT).
  В отрендеренных Markdown и AsciiDoc neurodoc-ссылки остаются кликабельными: переход
  такой же, как из редактора, а http-адреса открываются в браузере. Ссылки внутри
  блоков кода остаются кодом.
- **Копирование** — две кнопки в тулбаре: ссылка `<имя-файла>` и содержимое файла целиком.
- **Tab / Shift+Tab** — отступ 4 пробелами (символ табуляции не вставляется);
  работает и на выделенных строках.
- **Автоотступ** — при переносе строки сохраняется отступ предыдущей строки.
- **Работа со строками** (как в IntelliJ IDEA) — Shift+Alt+↑/↓ перемещает текущую
  строку вверх/вниз; Shift+Delete вырезает (выделение — как обычно, без выделения —
  всю текущую строку в буфер); Ctrl+Y удаляет текущую строку без копирования в буфер;
  повтор (Redo) — Ctrl+Shift+Z. Каждая операция откатывается одним Ctrl+Z.
- **Темы** — Система / Светлая / Тёмная (тёмная — графитовая, в стиле Блокнота Windows 11);
  настройка шрифта, размера и междустрочного интервала (0.8–3.0). Настройки открываются
  полупрозрачной шестерёнкой в углу.
- **Встроенные шрифты** — Inter и JetBrains Mono поставляются вместе с приложением
  (Assets\Fonts, лицензия SIL OFL) и при первом запуске автоматически устанавливаются
  для текущего пользователя (без прав администратора) — иначе текстовый стек
  Windows App SDK их не видит. Если после самого первого запуска встроенный шрифт
  не применился к тексту, перезапустите приложение — кэш шрифтов DirectWrite обновится.
  «Anthropic Sans» присутствует в списке выбора, но это проприетарный шрифт — он
  применится, только если установлен в системе.

## Как реализована подсветка ссылок

Редактор — `RichEditBox` в plain-text-режиме. Ссылки ищутся регулярным выражением,
их прямоугольники берутся из `ITextRange.GetRect`, и поверх текста рисуются
интерактивные «чипы»-пилюли акцентного цвета (курсор-рука, hover, клик — переход).

Ссылка имеет вид `[текст](uuid)`: текст ссылки встроен прямо в предложение, как в
Markdown. Кнопка «Новая ссылка» подставляет текст сама: выделили фрагмент — он станет текстом
ссылки; ничего не выделяли, но каретка стоит на слове (внутри или у края) — текстом
ссылки станет это слово. В обоих случаях он же ложится первой строкой нового файла,
то есть становится его заголовком. Если каретка в пустом месте, ссылка вставляется
без текста, как раньше.

Текст ссылки — всегда одна строка файла. Если выделение захватило несколько абзацев
или символ `]`, обе кнопки откажутся и объяснят причину: склеить абзацы или выкинуть
символ молча было бы правкой, которую никто не заказывал. Перенос длинной строки по
ширине окна к этому отношения не имеет — в тексте его нет, выделять через перенос
можно свободно. Пробелы по краям выделения в текст ссылки не входят и не пропадают.

Обычно ссылка показывается компактно: UUID скрывается,
на виду остаётся только текст ссылки, а ссылка без текста показывается кружком. В этом
режиме UUID прячется средствами RichEdit — единственное место, где документ форматируется.
Чтобы Ctrl+Z отменял правку, а не «разворачивал» ссылку, отмена и повтор пропускают
шаги, не изменившие текст.

Кнопка «Как есть» над текстом показывает файл без всякого форматирования — ровно так,
как он лежит на диске: ссылка видна целиком, подсветки нет. Это режим для ручной правки
символов; он запоминается между запусками.

Кнопка «Связать» (Ctrl+L) делает ссылкой уже написанный текст: скопируйте ссылку на
нужный файл кнопкой «Копировать ссылку», вернитесь, выделите слова — и они станут
текстом ссылки на этот файл. Кнопка доступна, только когда в буфере действительно
лежит ссылка на существующий файл каталога, а выделение не задевает другую ссылку.
Путь до цели пересчитывается от текущего файла, поэтому связывать можно и в root,
и в файлах `_content`.

Текст ссылки подчёркнут. Снять ссылку, оставив текст, — Ctrl+U: каретку внутрь ссылки
и нажать. Иначе до неё не добраться: служебная часть ссылки скрыта. Вставить ссылку
внутрь другой ссылки нельзя — приложение об этом предупредит.

Если файлы изменила другая программа (git, внешний редактор), редактор подхватит это сам.
Принудительно — кнопка «Обновить» или F5. Свои несохранённые правки при этом не затираются.

Ссылка может вести не только на файл из `_content`, но и на файл в собственном формате
из соседней папки — путь при этом считается от того файла, где написана ссылка:
`[auth.start](../contract/auth/start.yaml)`. Такой файл открывается в том же окне и
сразу в подходящем виде: формат определяется по расширению и включается автоматически.
Чтобы править его как текст, достаточно выключить кнопку формата.

Ссылок за пределы каталога не бывает: путь, ведущий наружу, ссылкой не считается и
попадает в список битых.

Каталог прежнего формата (со ссылками `<uuid>`) приложение предлагает преобразовать при
открытии проекта. Перед изменением создаётся резервная копия всего каталога.

Прокрутка устроена нетипично: в Windows App SDK координатные API RichEdit (TOM)
не отражают прокрутку, поэтому редактор растёт по высоте содержимого внутри
внешнего `ScrollViewer`, а чипы лежат в том же прокручиваемом контейнере и
движутся вместе с текстом. Видимость каретки при наборе/навигации поддерживается
вручную (SelectionChanged → ChangeView).
